Citing ChiMorse
===============

ChiMorse separates citation of the software, the scientific methodology, and
the reference dataset. Cite the research objects that your work actually uses.

Software
--------

The repository root contains ``CITATION.cff``. GitHub's **Cite this repository**
interface can export these software metadata. A persistent software DOI can be
added here after the first tagged GitHub release is archived on Zenodo.

Scientific paper
----------------

If you use the Fourier--Morse methodology or scientific results described in
the accompanying study, cite:

   Hadis Ghodrati, Sibylle Gemming, Florian Guenther, and Jeffrey Kelling,
   *A Symmetry-Constrained Fourier--Morse Framework for Compact Anisotropic
   Interaction Potentials in Surface Self-Assembly.* Publication details and
   DOI to be added when available.

Reference dataset
-----------------

If you use the alphaPA SCC-DFTB interaction data, cite the archived dataset
separately. The software currently registers the version-specific DOI
``10.5281/zenodo.21904448`` so the examples do not silently move to a later
record version.

Before the public release, replace publication placeholders with the final
bibliographic metadata once those records exist; do not replace versioned
identifiers used for reproducibility with an unspecified "latest" record.
